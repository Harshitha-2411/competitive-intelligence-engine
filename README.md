# AI Tools Competitive Intelligence & Pricing Strategy Engine

## Overview

This project was developed as part of the Aarivya Labs Data Analyst Internship.

The objective is to analyze AI tool competitors, compare pricing strategies, identify market positioning, and generate strategic business recommendations.

---

## Features

- Web Scraping
- Competitor Analysis
- SQLite Database
- Data Cleaning
- Pricing Analysis
- Market Segmentation
- Streamlit Dashboard
- Recommendation Engine
